# car-hunt — выбор первого б/у авто (РФ)

## Критерии

| Критерий | Значение |
|---|---|
| Бюджет | 600–700 т.р. (плюс ~30–50 т.р. на диагностику, ОСАГО, первое ТО) |
| Назначение | первый автомобиль |
| Обслуживание | недорогое, массовые запчасти |
| Надёжность | проверенные моторы и коробки, без «проблемных» трансмиссий |
| Коробка | любая: механика или надёжный автомат; без роботов и проблемных АКПП |
| Внешний вид | «нормальный» — не Matiz, не Нива |
| Регион | вся РФ (перегон/доставка из другого города — ок) |

## Структура

- [`SHORTLIST.md`](SHORTLIST.md) — рейтинг моделей, что брать и чего избегать.
- [`cars.yaml`](cars.yaml) — база моделей: годы, мотор/коробка, цены, слабые места, оценки.
- [`cars/`](cars/) — заметки по конкретным объявлениям (`cars/<дата>-<модель>-<город>.md`).
- [`reports/`](reports/) — ежедневные сводки `YYYY-MM-DD.md` (16:00 GMT+7).
- [`config.yaml`](config.yaml) — параметры поиска, которые читает ежедневная задача.
- [`CHECKLIST.md`](CHECKLIST.md) — как осматривать машину перед покупкой.

## Ежедневная сводка

Задача Claude (scheduled task `car-hunt-daily`) каждый день в 16:00 GMT+7:

1. ищет свежие новости и цены рынка б/у (Автостат, Авито Авто, Авто.ру, Дром);
2. смотрит объявления по моделям из шорт-листа в регионе из `config.yaml`;
3. пишет `reports/YYYY-MM-DD.md`, обновляет цены в `cars.yaml`;

## Парсер Авито

Запускаешь сам, на своём ПК:

```bash
npm i && npx playwright install chromium   # один раз
npm run avito          # одна попытка
npm run avito:wait     # ждать, пока Авито пустит (проба раз в 30 мин, до 12 ч), потом парсить
npm run avito:force    # перезапустить, даже если сегодня уже спарсено
```

Результат: `data/avito/YYYY-MM-DD.json` (данные) и `data/avito/YYYY-MM-DD.md` (карточки + таблица всех объявлений). Ежедневная сводка подхватывает свежий файл сама.

- Модели — из `cars.yaml`, бюджет/коробка/пробег — из `config.yaml`.
- Выдача: до 16 страниц, пауза 8–15 с. Затем подробные карточки 10 лучших (не битых, до 2 на модель): владельцы по ПТС, ПТС, модификация, привод, руль, цвет, VIN (если открыт), упоминание юрлиц/лизинга/такси, тип продавца, описание. Имена и телефоны продавцов не собираются.
- При 403/429/капче останавливается и сохраняет то, что успел (`status: partial` / `blocked`), код выхода всегда 0.
- Настройки через env: `AVITO_PROBE_MIN`, `AVITO_WAIT_HOURS`, `AVITO_MAX_PAGES`, `AVITO_DETAILS`, `AVITO_HEADLESS=1` (без окна — блокируют быстрее).

**Почему блокирует:** через VPN выход идёт с IP датацентра — Авито режет такие первыми. Помогает пустить `avito.ru` и `avito.st` мимо VPN (правило «direct» в клиенте VPN).

Отложенный запуск (cron, каждый день в 15:00 по часам ПК):

```bash
0 15 * * * cd ~/WebstormProjects/car-hunt && /opt/homebrew/bin/npm run -s avito:wait >> data/avito/cron.log 2>&1
```
